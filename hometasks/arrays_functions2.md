#### Задача 1.
Написать функцию
```cpp
int countValue(const int* A, int n, int x)
```
которая возвращает количество элементов массива `A` размера `n`, равных `x`.

Например, для массива `{3, 1, 3, 5, 3}` при `x = 3` функция должна вернуть `3`.

#### Задача 2.
Написать функцию
```cpp
int firstMinIndex(const int* A, int n)
```
которая возвращает индекс минимального элемента массива. Если минимум встречается несколько раз, вернуть индекс его первого вхождения. Считать, что `n > 0`, а индексы начинаются с нуля.

Например, для массива `{7, 2, 5, 2}` функция должна вернуть `1`.

#### Задача 3.
Написать функцию
```cpp
bool isNonDecreasing(const int* A, int n)
```
которая проверяет, что каждый элемент массива, начиная со второго, больше или равен предыдущему. Для массива из одного элемента функция должна вернуть `true`.

Например, для массива `{1, 2, 2, 5}` функция должна вернуть `true`, а для массива `{1, 4, 3}` — `false`.

#### Задача 4.
Написать функцию
```cpp
void reverseArray(int* A, int n)
```
которая меняет порядок элементов исходного массива на обратный. Дополнительный массив использовать нельзя.

Например, из массива `{4, 7, 1, 9, 2}` должен получиться массив `{2, 9, 1, 7, 4}`.

#### Задача 5.
Написать функцию
```cpp
int removeValue(int* A, int n, int x)
```
которая записывает все элементы, отличные от `x`, в начало исходного массива, сохраняя их порядок. Функция возвращает количество оставшихся элементов. Значения за пределами этой части массива могут быть любыми.

Например, для массива `{2, 8, 2, 5, 2, 7}` при `x = 2` функция должна вернуть `3`, а первые три элемента массива должны стать `{8, 5, 7}`.
